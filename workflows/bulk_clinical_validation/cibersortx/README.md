# Single-cell-reference to bulk deconvolution

This module contains the CIBERSORTx hand-off described in the manuscript.
The target dataset is the Japan-UTUC bulk RNA-seq cohort; the reference is the
manually annotated UTUC single-cell dataset.

## Input and output handling

- `01_prepare_inputs.R` selects at most 300 cells per fine-grained annotated
  state, exports the raw-count single-cell reference and preserves the supplied
  Japan-UTUC bulk expression scale when writing the mixture matrix.
- The two matrices are submitted to the registered CIBERSORTx web service to
  construct a custom signature matrix and estimate relative fractions with the
  manuscript-stated default settings.
- `02_import_fractions.R` validates the returned Job 2 table, separates
  CIBERSORTx QC columns from cell-state fractions, checks the 158 sample IDs and
  creates `japan_utuc_program_scores.tsv` for the clinical models.

CIBERSORTx credentials, executables, signature matrices generated by the
service, patient expression matrices and patient clinical records are not
distributed. The repository records the reproducible preparation and result
handoff without copying third-party source.

## Run

```bash
Rscript workflows/bulk_clinical_validation/cibersortx/01_prepare_inputs.R \
  --config config/parameters.yaml \
  --input-dir data/processed \
  --output-dir outputs/cibersortx_inputs \
  --seed 20260730 --threads 4

# Upload CIBERSORTx_scRNA_reference.txt and CIBERSORTx_bulk_mixture.txt,
# construct the custom signature matrix, and run relative fraction estimation.

Rscript workflows/bulk_clinical_validation/cibersortx/02_import_fractions.R \
  --config config/parameters.yaml \
  --input-dir data/processed \
  --output-dir outputs/cibersortx_import \
  --seed 20260730 --threads 4
```
