# Project-authored spatial and clinical workflows

- `01_pair_burden.py`: q05-based within-spot and section-level pair burden.
- `02_boundary_profiles.R`: section-resolved posterior-mean abundance profiles
  across a signed tumour boundary.
- `03_japan_clinical_models.R`: rank-normalised cellular-program models for
  muscle invasion and disease-specific survival.

The scripts preserve the distinction between conservative q05 pair burden and
posterior-mean continuous boundary profiles.
